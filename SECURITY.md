# Security policy

Skillsmo contains natural-language instructions for AI coding agents. A harmful or inaccurate instruction, unsafe tool-use recommendation, leaked credential, or vulnerable example should be reported.

## Supported versions

All packages are experimental. Security reports should name the affected commit, package path, and relevant host/version where applicable. There are no stable releases yet.

## Report a vulnerability privately

Use GitHub's **Security** tab to submit a private vulnerability report if private vulnerability reporting is enabled for this repository. If that option is unavailable, contact `helx0071` through the GitHub profile and request a private disclosure channel.

Do not publish exploit details, credentials, personal data, or an unpatched vulnerability in a public issue or pull request. Include a concise description, impact, reproduction steps that do not expose secrets, and a suggested mitigation if known.

Maintainers will acknowledge reports as time permits. No response-time commitment is currently offered.
