## Third-party sources

The [source register](../SOURCES.md) records research inputs and provenance. A link, citation, repository name, or source note is not a copy of the linked work and does not grant permission to reuse it.

Skillsmo's current packages are written independently. Upstream repositories, skill files, prompts, examples, scripts, datasets, media, images, and other assets are not included by default. Source projects remain under their own licenses and notices.

Before adding third-party material:

1. Identify the exact source, file or asset, revision, and applicable license or notice.
2. Confirm that redistribution and modification are permitted for the intended use.
3. Preserve required copyright, attribution, and license notices.
4. Document the material and its scope in the package and source register.
5. Add a specific notice when the root MIT License does not apply to that material.

Do not treat a repository-level license as proof that every file in a project or linked dependency uses the same terms. If rights are unclear, keep the material out and write an independent description of the relevant idea.
