# Code of Conduct

Skillsmo welcomes contributions from people with different backgrounds, experience levels, and perspectives. Everyone participating in repository issues, pull requests, reviews, or project discussions is expected to help keep the space constructive and safe.

## Expected behavior

- Discuss ideas and work respectfully; critique proposals without attacking people.
- Make room for different experience levels and communicate technical disagreement in good faith.
- Give useful context, assume good intent where reasonable, and accept corrections.
- Respect privacy. Do not publish another person's private information or credentials.

## Unacceptable behavior

Harassment, threats, discriminatory abuse, personal attacks, deliberate intimidation, unwanted sexual attention, doxxing, and repeated disruptive conduct are not acceptable. Do not use the repository to publish malicious instructions, secrets, or personal data.

## Maintainer response

A maintainer may remove or edit harmful content, ask a participant to stop, restrict participation temporarily, or block further participation when conduct continues or creates a serious risk. The response will be proportionate to the situation. Reports will be handled as privately as the available GitHub tools allow.

## Reporting

For conduct issues, contact the repository maintainer through the GitHub profile for `helx0071`. Do not include sensitive personal data in a public issue. If you cannot reach the maintainer or have a concern about a maintainer, use GitHub's available reporting channels.

This code applies to project spaces maintained through this repository, including issues, pull requests, reviews, and discussions.
