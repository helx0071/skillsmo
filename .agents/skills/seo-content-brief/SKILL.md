# SEO content brief

## Goal

Guide an original, useful page with clear audience value, evidence requirements, and search intent fit.

## Workflow

1. Define audience, task, business context, geography, page type, expertise available, and the action readers should be able to take.
2. Research current queries and representative result pages using available sources; record search intent, subquestions, competing formats, and gaps without copying competitor copy.
3. Propose a focused angle, title direction, structure, key entities, internal links, evidence or first-hand expertise needed, and content exclusions.
4. Flag sensitive or high-impact claims for expert review and attach primary sources or data requirements.
5. Set editorial acceptance checks for usefulness, originality, accuracy, authorship, freshness, accessibility, and appropriate search metadata.

## Decision rules

- Use keyword data as evidence about demand, not as a mandate to repeat phrases.
- Prefer a narrower useful answer over a generic page that covers every adjacent query.
- Mark unavailable volume, ranking, or conversion data as unknown.

## Boundaries

- Do not generate mass pages that add no unique value or target search engines over readers.
- Do not invent experience, expertise, statistics, quotes, or citations.

## Completion standard

Return the requested artifact or findings with enough evidence for a reviewer to understand what changed, what was checked, and what remains uncertain. Distinguish observed facts, inferred risks, and unverified assumptions. Keep the scope tied to the user's request.
